📄 React Day 17 – Form Validation App

A small React project focused on handling form input, validating fields in real time, and providing helpful UI feedback.
This exercise continues your daily React training and builds practical skills used in real-world login/registration forms. 🚀

✨ Features

🔤 Email & password state management

📝 Real-time validation

❌ Error messages for each field

✔️ Disabled submit button until form is valid

🎨 Clean, simple UI layout

🧠 What I learned

How to manage multiple pieces of form state with useState

How to validate input inside onChange handlers

How to store error messages inside an object

How to conditionally enable/disable the submit button

Why validation logic is separated from the JSX part of the component
